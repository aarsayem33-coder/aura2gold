# Pullback & Timing Projection System (Math + AI)

This feature adds a new predictive layer to **Aura Gold Alerts** called **Pullback & Timing Projections**. Instead of just evaluating immediate setups, the system will identify key price zones (unmitigated Order Blocks, Fair Value Gaps) and calculate the mathematical & AI-validated time-to-reach and price action direction when price reaches that level. This will support both Forex trades (limit orders with SL/TP) and Fixed-Time Trades (FTT with precise expiry).

---

## User Review Required

> [!IMPORTANT]
> **Gemini API & Costs**: The AI validation step requires a prompt analyzing multiple timeframes, indicators, and structure levels. To optimize costs and avoid API limits, AI validation will run:
> 1. In the background when a major mathematical zone is breached/entered.
> 2. On-demand when the user clicks the "Run AI Projection" button.
> We will continue to use the configured model (`gemini-2.5-flash` or `gemini-2.5-pro` from `.env.local`).

#### [NEW] [projectionEngine.js](file:///Users/abdullahalredowan/Library/CloudStorage/OneDrive-SharedLibraries-Onedrive/Documents/PERSONAL/DEVELOPMENTS/aura-gold-alerts/backend/projectionEngine.js)
Create a new engine module responsible for the mathematical (deterministic) timing and entry calculations:
*   **Zone Extractor:** Parse the latest candles to locate unmitigated **Order Blocks (OB)** and open **Fair Value Gaps (FVG)**.
*   **Distance Calculator:** For each zone:
    *   Compute the point distance from current close: $D = |P_{\text{current}} - P_{\text{zone\_boundary}}|$.
*   **Volatility Speed (ATR) Estimator:**
    *   Calculate timeframe ATR (e.g. M5 or M15 or H1 ATR based on the chart timeframe).
    *   Calculate average point movement speed per candle.
*   **Mathematical Timing Estimate:**
    *   Compute expected number of candles to reach target: $N = \frac{D}{\text{ATR}}$.
    *   Compute predicted duration: $\text{Minutes} = N \times \text{Timeframe Duration}$.
    *   Calculate the projected absolute time: $\text{TargetTime} = \text{Date.now()} + \text{Minutes} \times 60 \times 1000$.
*   **Suitability Classifier:**
    *   Flag if the projection is suitable for a standard **Forex Limit Order** (e.g. higher timeframe trend matches direction).
    *   Flag if suitable for **FTT (Fixed-Time Trading)**, and output the recommended FTT Expiry (e.g. if time-to-reach is 20 minutes, suggest a 15m or 30m expiry).
